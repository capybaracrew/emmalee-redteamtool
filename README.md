# Emmalee Carpenter Red Team Tool

A tool to make a custom password policy. It can be customized by changing the Test-PasswordRules function.
It is a powershell script that can be easily run after downloaded.

Steps for Use:

1. Download the .ps1 file on the domain server.
2. Move the script into C:\Windows\System32
3. Run the script in powershell.


This was created using inspiration from RITSEC IRSec 2024. It also
integrates information from ChatGPT.
